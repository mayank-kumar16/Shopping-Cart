# 🛒 React Shopping Cart App

A modern **E-commerce Shopping Cart application** built using **React**, featuring dynamic product listing, cart management, and API integration.

---

## 🚀 Features

- 📦 Fetch products from API
- 🛍️ Add to Cart functionality
- 🔁 Update quantity using `prevState`
- 🧠 Global state management using Context API
- 🪝 Custom Hook (`useCart`)
- 🔍 Dynamic Product Details page
- 🚦 Loading & Error handling
- 🧭 React Router (Nested Routes)
- 🎨 Responsive UI with Tailwind CSS

---

## 🧱 Project Structure

```
src/
│
├── components/      # Reusable UI components
├── pages/           # Route pages (Home, Cart, ProductDetails)
├── context/         # Cart Context
├── hooks/           # Custom hooks (useCart)
├── services/        # API calls
├── routes/          # Router configuration
├── layouts/         # Layout wrapper
├── utils/           # Helper functions
```
